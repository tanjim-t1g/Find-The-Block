# PlaceholderAPI Reference

Supported placeholders for tablists, scoreboards, and in-game holograms.

---

## Global Match Placeholders

| Placeholder | Description | Example |
| :--- | :--- | :--- |
| `%findtheblock_state%` | Current match state enum. | `IN_GAME`, `LOBBY` |
| `%findtheblock_state_display%` | Formatted state with color code. | `In Game`, `Lobby` |
| `%findtheblock_target%` | Name of the target block or item. | `IRON_INGOT` |
| `%findtheblock_time%` | Elapsed match time in MM:SS format. | `04:23` |
| `%findtheblock_contestants%` | Count of alive participants in the match. | `8` |

---

## Personal Player Stats

| Placeholder | Description | Example |
| :--- | :--- | :--- |
| `%findtheblock_wins%` | Total number of 1st-place victories. | `14` |
| `%findtheblock_played%` | Total matches entered. | `32` |
| `%findtheblock_best_time%` | Fastest win time achieved. | `01:45` |

---

## Top Leaderboards (Rank 1 to 10)

Replace `1` with any rank from `1` through `10`:

| Placeholder | Description |
| :--- | :--- |
| `%findtheblock_top_1_name%` | Username of rank #1 player. |
| `%findtheblock_top_1_wins%` | Win count of rank #1 player. |
| `%findtheblock_top_1_time%` | Fastest win time of rank #1 player. |
