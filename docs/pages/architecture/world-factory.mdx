# World Gen & Nether

How fresh Overworld and Nether worlds are generated with zero server lag.

---

## Background World Factory Pipeline

Traditional minigames freeze the server when creating a new world. FindTheBlock prevents lag using a background generation pipeline:

- **Standby Queue:** It keeps a pre-generated world pair ready before the match starts.
- **Paced Chunk Gen:** New chunks are generated asynchronously at **30 chunks per second**, keeping server TPS at a locked 20.0.
- **Automatic Cleanup:** When a match concludes, the temporary worlds are unloaded and wiped from disk completely.

---

## Nether & The End Dimensions

- **Nether:** An Overworld and Nether world pair is generated with the exact same seed. Nether portals link with standard 1:8 coordinate scaling.
- **The End:** Supported on-demand. An End dimension (`ftb_<id>_the_end`) is only loaded if a player enters an End portal. If no one goes to the End, it is never loaded to save server resources.
- **Automatic Cleanup:** When the match finishes, all match dimensions (Overworld, Nether, and End) are automatically unloaded and deleted from disk.
