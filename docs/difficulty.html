Difficulty & Recipes

Configure item tiers and display in-game crafting recipes.

Difficulty Tiers

Difficulty Target Items Focus & Style
EASY (1 pt) Diamond Ore, Amethyst Block, Calcite, Dripstone, Moss, Glow Lichen, Packed Ice, Magma, Dead Corals, Red Sand, Terracotta, Podzol Surface & biome exploration, basic underground resources
NORMAL (3 pts) Ancient Debris, Crying Obsidian, Sea Lantern, Prismarine, Shroomlight, Nylium, Resin Blocks, Sculk Sensors, Slime Block, Emerald Ore, Deepslate Diamond Ore, Sponge Deep mining, Nether travel, ocean monuments, Trial Chamber exploration
HARD (5 pts) Mob Heads, Heavy Core, Shulker Boxes, Netherite Block, Beacon, Ender Chest, Lodestone, Purpur Block, Chorus Flower, End Stone Bricks, Mycelium The End exploration, boss encounters, mushroom islands, endgame crafting

Starting with a Difficulty

Pass the difficulty as an argument, or choose it visually in the in-game Mode Selection GUI:

  • /start easy (Party leader ready-check)
  • /start normal
  • /start hard
  • /ftb startall [tier] (Admin match for all lobby players)

If omitted, the default tier defined in config.yml is used.

Recipe Viewer GUI

Players can check how to craft the target item at any time:

  • Run /recipe in chat.
  • A 3 × 3 crafting table GUI opens displaying the exact pattern and ingredients.
  • Works for all standard shaped and shapeless vanilla recipes.
